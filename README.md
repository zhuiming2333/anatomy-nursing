# 系统解剖学 · 学习站

给护理专业复习《系统解剖学》做的静态网页：**背名词解释、背简答、默写自评、刷选择/填空、看图记忆**。
纯静态、无后端、无网络依赖，双击 `index.html` 就能用，也可以直接传到 GitHub Pages / Cloudflare Pages / Netlify。

---

## 一、怎么打开

### 电脑上（最简单）
双击 `index.html`，用 Chrome / Edge 打开即可。所有功能都在本地跑，不需要联网。

### 手机上：局域网（不用部署）
1. 双击 **`手机打开.bat`**，会弹出一个黑色窗口，里面有三行地址。
2. 手机连**和电脑同一个 Wi-Fi**，在浏览器里输入窗口里显示的 `http://10.x.x.x:8088/`（通常是 WLAN 那个 IP）。
3. 第一次运行 Windows 可能弹「安全中心」提示，选**允许访问**。
4. 关掉黑窗口就停止服务；网站在文件夹里，随时还能再开。

> 手机和电脑不在一个 Wi-Fi、或者宿舍网络隔离（很多校园网会隔离设备）时，这个方式不通，用下面的「部署到网上」。

### 手机上：部署到公网（推荐，一次搞定长期可用）
见文末「六、部署到公网」。部署后会得到一个网址，手机随时打开，还能「添加到主屏幕」，**没网也能背**（已内置离线缓存）。

## 二、五个页面怎么用

| 页面 | 干什么 |
|---|---|
| **今日** | 今日待复习数量、每日目标进度、连续打卡、各章掌握度、随机一条口诀。 |
| **背诵** | 名词解释卡：先看名字回忆 → 「显示答案」→ 选「忘了 / 模糊 / 会了」。还能切到**问答题**（逐条揭示采分点）和**口诀**。 |
| **练习** | 综合卷（6 选择 + 3 填空 + 1 默写）、最佳选择、填空、默写；做错自动进**错题本**，可只练错题。 |
| **图解** | 两张模式：**图片**（解剖图 + 6 张手绘通路图，点开放大、带标注点）和 **3D 模型**（真·可旋转的人体结构，9 个场景，点哪个结构显示名字，并直接列出相关的名词解释）。 |
| **速查** | 全文搜索名词解释 / 问答题 / 中英术语，按章节筛。考前当小词典用。 |

### 3D 模型怎么用

**图解 → 3D 模型**，或者**背诵卡上那个「模型」按钮**（推荐后者，它就是为「边背边看」做的）。

| 场景 | 包含结构 |
|---|---|
| 泌尿系统 | 左/右肾、左/右输尿管、膀胱、尿道 |
| 男性生殖 | 睾丸、附睾、输精管、精囊、前列腺（各左右） |
| 眼球结构 | 角膜、巩膜、虹膜睫状体、晶状体、玻璃体、视网膜、眼前房 |
| 内分泌腺 | 左/右肾上腺、垂体 |
| 下肢骨 | 髋骨、骶骨、股骨、髌骨、胫骨、腓骨 |
| 脊柱 | 第 3–7 颈椎、12 胸椎、5 腰椎、骶骨 |
| 胸廓 | 胸骨柄/体/剑突、左右各 12 肋 |
| 颅骨 | 额、顶、颞、枕、蝶、下颌、颧、上颌、鼻、腭、犁骨 |
| 消化管 | 肝、胃、胆囊、胰、食管、十二指肠、小肠、大肠、阑尾 |

- 手指**拖动**旋转、**双指**缩放、**点结构**看名字；「只看选中」把其他结构藏起来，专心看一个。
- 选中后下方会自动列出**和这个结构相关的名词解释**，点一下就能看释义 —— 这就是「图和知识点对上」的地方。
- 背诵卡里的「模型」按钮会自动**定位到跟这个词同名的结构**（比如背「膀胱三角」，打开就选中膀胱）。

**没有 3D 的章节**：呼吸、循环、神经、女性生殖、腹膜。原因很实在 —— 开源数据里肺实质、心脏整体、小脑、脑干、脊髓、子宫、甲状腺这些没有独立模型，硬拼会错得离谱，所以这几章继续用图片和手绘通路图，不强凑。

小技巧：
- 背诵卡里点「**挖空自测**」，释义里的关键词会变成横线，先自己填，点横线揭示 —— 比整段重读有效得多。
- 默写题会按**采分点关键词**打分，只会告诉你「命中 4/6」，不判对错，命中的词条会打勾，没命中的列出来。
- 电脑上：`空格` 显示答案，`1 / 2 / 3` 分别对应「忘了 / 模糊 / 会了」。

## 三、复习是怎么排的

用的是简化版间隔重复（Leitner 盒子）：

| 评价 | 盒子变化 | 下次出现 |
|---|---|---|
| 忘了 | 回到 0 | 15 分钟后 |
| 模糊 | 不升不降 | 半天到 8 天（按当前盒子减半） |
| 会了 | +1 盒 | 1 / 2 / 4 / 8 / 16 / 30 / 60 天依次拉长 |

盒子 ≥ 4 记为「已掌握」，首页的章节掌握度就是按这个算的。所以**首页数字不会因为今天背了很多就暴涨**，它反映的是真正记住的条目。

## 四、学习记录

- 记录存在**当前浏览器**里（localStorage），换浏览器 / 清理缓存 / 换设备都不会跟着走。
- 右上角齿轮 → **导出** 得到一个 JSON；在新设备上 → **导入** 同一个文件即可接着背。
- 齿轮里还能：切换深色模式（夜里背）、改每日目标、清空进度。

## 六、部署到公网

整个文件夹就是网站，**不需要构建**。三种方式任选：

### A. Netlify Drop（最快，30 秒）
1. 打开 <https://app.netlify.com/drop>
2. 把 `解剖学习站` 文件夹（或我打包好的 `解剖学习站-上传用.zip` 解压后的文件夹）整个拖进去
3. 等几秒，得到一个 `https://xxx.netlify.app` 网址 —— 手机直接开

### B. Cloudflare Pages
1. <https://dash.cloudflare.com/> → Workers & Pages → Create → Pages → **Upload assets**
2. 把文件夹拖进去，Deploy
3. 得到 `https://xxx.pages.dev`

### C. GitHub Pages
1. 新建一个仓库（名字建议用英文，如 `anatomy-site`），设为 Public
2. 把文件夹里的**所有文件**上传到仓库根目录（网页上 Add file → Upload files，可以整个文件夹拖进去）
3. Settings → Pages → Source 选 `Deploy from a branch`，Branch 选 `main` / 根目录，Save
4. 一两分钟后访问 `https://你的用户名.github.io/anatomy-site/`

> 仓库里带了一个 `.nojekyll` 空文件，作用是让 GitHub Pages 不要用 Jekyll 处理站点，别删。

### 部署后的小加分
手机上打开网址 → 浏览器菜单 →「添加到主屏幕」。之后像 App 一样全屏打开，且**已经访问过一次后没网也能用**（`sw.js` 会缓存全部页面、题库和图片）。

## 七、技术说明

- 零依赖、零构建：原生 HTML/CSS/JS，数据以 `window.ANAT.*` 全局对象注入（所以 `file://` 直开也不会被 CORS 拦）。
- 目录结构：
  ```
  index.html                 入口
  assets/css/app.css         样式（含深色模式、手机底部标签栏）
  assets/js/app.js           路由 / 间隔重复 / 背诵 / 做题 / 图解 / 速查
  assets/js/data/core.js     章节体系 + 25 条口诀与易错点
  assets/js/data/terms.js    名词解释 89
  assets/js/data/qa.js       简答 92（含采分点）
  assets/js/data/mcq.js      选择 120
  assets/js/data/fill.js     填空 79
  assets/js/data/vocab.js    中英术语 105
  assets/js/data/images.js   图片清单
  assets/img/                解剖图 + svg/ 手绘通路图
  server.ps1 / 手机打开.bat   局域网小服务器（仅本地用，部署时可不上传）
  ```
- 适配：手机底部 5 个标签、桌面顶部横向标签；深色模式；系统字体；`prefers-reduced-motion` 降级。
